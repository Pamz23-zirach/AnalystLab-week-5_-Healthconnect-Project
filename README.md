# AnalystLab-week-5_-Healthconnect-Project
HealthConnect Appointment No-Show Analysis

Project Overview

This project analyzes HealthConnect appointment data to understand patient attendance and identify factors associated with appointment no-shows.

Key Findings

* 5,000 appointments analyzed
* 48.46% no-show rate
* 46.28% attendance rate
* Previous no-shows were strongly associated with future no-shows
* Longer booking lead times were associated with higher no-show rates
* Appointments with reminders had lower observed no-show rates
* SMS recorded the lowest observed no-show rate among reminder channels

Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

Next Steps

The next phase will focus on developing a predictive model to identify appointments at higher risk of no-show and support targeted patient engagement.
